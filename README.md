# Unitn Lectures

This repository contains AI-generated summaries of the courses I follow at the University of Trento.

I found these types of summaries very useful for studying and reviewing.

## Repository structure

Each course has its own directory under `lectures/`. The source `.pdf` files and the Typst sources are kept in `lectures/<course>/source/<lesson>/`, while the compiled summaries are placed in `lectures/<course>/` as `<course>-<lesson>.pdf`.

## Used model

The summaries are generated by DeepSeek V4.1 Flash, through OpenCode, following the instructions written in `PROMPT.md`.

## How to use this repo

You are free to fork this repo and use it as a template or experiment on it.

If your IDE supports it, this repo can be opened on a devcontainer, which starts a headless OpenCode server accessible from your local machine with the `opencode attach` command.

The devcontainer configuration points to `docker-compose.yml`, so if you prefer you can run it on a server and leave OpenCode working even if your local machine is powered off.

### Instructions

First create your env file from the example and fill in your OpenRouter API key (or the API key for another provider supported by OpenCode):

```sh
cp .devcontainer/.env.example .devcontainer/.env
```

Then start the devcontainer. If your IDE supports devcontainers, just reopen the repo in the container. Otherwise run it from the repo root:

```sh
docker compose -f .devcontainer/docker-compose.yml up -d --build
```

The container starts a headless OpenCode server on port `4000`, as defined in `.devcontainer/entrypoint.sh`. Attach to it from your local pc with:

```sh
opencode attach http://localhost:4000
```

If the container runs on another machine, replace `localhost` with its address, and make sure the `--hostname` in `.devcontainer/entrypoint.sh` binds to an address reachable from outside the container.
