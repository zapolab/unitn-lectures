Introduction and motivation
Transistor linear dimensions could be scaled down by 30% (0.7×)
• their area decreases by approximately 50% (0.5×)
• the voltage, V, decreases by 30% (0.7×) to keep the electric field approximately constant
• capacitance, C, decreases by approximately 30% (0.7×)


Other implications are:
• circuit delay decreases by approximately 30% (0.7×), allowing operating frequency, f, to
  increase by about 40% (1.4×)
• dynamic power per transistor decreases by approximately 50% (0.5×)
• with approximately 2× transistor density, power density remains approximately constant
  (ideal Dennard scaling)

=== PAGE 64 ===
Introduction to Parallel Computing




Parallel Computing is the simultaneous use of multiple compute resources to solve a computational
problem
• A program is broken into discrete parts that can be solved concurrently
• Multiple instructions are executed at any moment in time, depending on the number of processors
• An overall control/coordination mechanism is employed
• Each PE executes its own instruction stream while multiple PEs execute simultaneously.

Introduction to Parallel Computing




The program should be able to:
• decompose the pieces of work that can be solved simultaneously;
• Execute multiple instructions at any moment in time;

The goal is to solve the problem in less time by exploiting multiple compute resources.

Parallel computing and performance

Portability is the capacity of software to run on different architectures or environments.
To this aim for example, OpenCL provides a programming model and level of abstraction to
match different architectures.


Performance portability: is the ability of the software to achieve a “consistent” level of
performance across multiple architectures.


Productivity reflects the effort required to develop, debug, tune, and maintain parallel
software.
• Productivity via parallel programming models (add more abstractions into a standard)
• Productivity via domain-specific programming models (e.g., identification algorithm
  primitives)
